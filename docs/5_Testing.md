# Проверка программы «Учёт студентов»

Программа проверялась двумя способами: автоматическими тестами и вручную через меню.

Проверка выполнена 24.11.2026 на macOS с Python 3.14. Автотесты дополнительно запускались на Python 3.9 и 3.12 — результат тот же.

## 1. Автоматические тесты

**Автотест** — это маленькая программа, которая сама вызывает функции приложения и сравнивает результат с ожидаемым. Тесты лежат в файле `src/test_app.py`.

Тесты работают с временной базой в оперативной памяти, поэтому настоящий файл `students.db` они не трогают.

### Как запустить

```bash
cd src
```

```bash
python3 -m unittest -v test_app
```

В Windows вместо `python3` пишите `python`.

### Что проверяет каждый тест

| Тест | Что проверяет |
|---|---|
| `test_add_and_show_student` | добавленный студент появляется в списке; средний балл без оценок пустой |
| `test_extra_spaces_are_removed` | лишние пробелы в ФИО и группе убираются |
| `test_empty_name_is_rejected` | пустое ФИО не принимается |
| `test_name_with_digits_is_rejected` | ФИО с цифрами не принимается |
| `test_duplicate_record_book_is_rejected` | нельзя добавить двух студентов с одним номером зачётки |
| `test_search_ignores_letter_case` | поиск по ФИО, группе и зачётке работает и не зависит от регистра русских букв |
| `test_empty_search_is_rejected` | пустой поисковый запрос не принимается |
| `test_update_student` | данные студента изменяются; свой номер зачётки можно оставить |
| `test_update_to_taken_record_book_is_rejected` | нельзя сменить номер зачётки на уже занятый |
| `test_unknown_student_is_rejected` | несуществующий ID или буквы вместо ID дают ошибку |
| `test_add_grades_and_average` | оценки сохраняются; средний балл 5 и 4 равен 4,5 |
| `test_wrong_grade_is_rejected` | оценки 1, 6, 0, −3, «пять» и пустая строка не принимаются |
| `test_grade_for_unknown_student_is_rejected` | нельзя поставить оценку несуществующему студенту |
| `test_delete_student_removes_grades_too` | при удалении студента его оценки тоже удаляются из базы |

## 2. Контрольные примеры (ручная проверка)

### Подготовка

Чтобы результаты совпали с таблицей, начните с чистой базы и учебных данных:

1. Удалите файл `src/students.db`, если он есть.
2. Выполните в папке `src` команду `python3 demo_data.py` — появится сообщение «Добавлено студентов: 5, оценок: 7.»
3. Запустите программу: `python3 main.py`.

Выполняйте примеры по порядку — они зависят друг от друга.
